# 体彩规律图 · 七星彩 & 排列五

中国体育彩票 **七星彩** 和 **排列五** 的走势图与规律分析网页，数据每日自动更新。

## 功能

- 📈 **走势图**：每期开奖号码按位展示，支持 30/50/100/200 期切换，四种着色方式（号码色 / 奇偶 / 大小 / 012路）
- 🔥 **号码频率统计**：各号码在每一位及总体的出现次数与占比（热力着色）
- ⏳ **遗漏统计**：各号码距离上次出现间隔的期数
- 🌡️ **冷热号分析**：近 10 期 / 近 30 期的热号与冷号排行
- 🎯 **最新一期摘要**：开奖号码、和值、奇偶比、大小比

## 玩法说明

| 彩种 | 位号 | 号码范围 | 开奖频率 |
|------|------|----------|----------|
| 七星彩 | 第 1-6 位 | 0-9 | 每周二、四、日 |
| 七星彩 | 第 7 位（特别号） | 0-14 | 同上 |
| 排列五 | 第 1-5 位 | 0-9 | 每日 |

## 数据更新

数据由 GitHub Actions 每日定时（北京时间 22:00）从中国体育彩票官方接口抓取并提交到仓库，GitHub Pages 自动重新部署。

手动触发更新：仓库 **Actions** 页面 → *Update Lottery Data* → *Run workflow*。

## 本地运行

```bash
# 1. 抓取最新数据
python3 fetch_data.py

# 2. 启动本地服务器
python3 -m http.server 8000
# 打开 http://localhost:8000
```
